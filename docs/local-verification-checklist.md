# Wallume 本地验收清单

本轮目标是确认现有功能在真实设备上正常运行；请记录每个失败步骤、页面截图和控制台输出，后续只根据可复现问题逐项修复。

## 启动与窗口

- [ ] 启动 `.app` 后主窗口正常显示，不是空白页。
- [ ] 关闭窗口再从菜单栏打开，内容正常重新出现。
- [ ] 在浅色和深色外观下浏览 图库、显示器、锁屏、性能、设置，文字和按钮均清晰可读。

## 导入与图库

- [ ] 点击“导入文件”和“导入文件夹”均能弹出到前台的系统选择器。
- [ ] 导入包含子目录的视频文件夹，确认子目录被扫描、隐藏文件和包内容被忽略。
- [ ] 确认队列展示总进度和单项进度；失败项不会阻塞后续项目。
- [ ] 测试“取消当前项”“取消全部”和失败项单独重试；已完成项目保留。

## 显示器壁纸

- [ ] 为每个已连接显示器选择、预览并应用一张壁纸。
- [ ] 测试填充、完整显示、拉伸铺满，以及暂停和继续播放。
- [ ] 正在被显示器使用的媒体无法从图库删除；更换壁纸后可以删除。

## macOS 26 锁屏安全

- [ ] 打开“锁屏”页，确认显示当前系统不支持旧锁屏同步，并提供系统壁纸设置入口。
- [ ] 页面不显示启用、选择 Aerial 槽或恢复系统锁屏壁纸等会写入旧机制的操作。
- [ ] 使用 Wallume 后连续锁屏、解锁两次；系统锁屏不应因 Wallume 变黑。

## 性能与设置

- [ ] 打开性能页，确认实时指标能更新；开始、取消并导出一次本地诊断。
- [ ] 切换启动与播放设置；打开 Wallume 数据和诊断数据目录。
- [ ] 导出诊断到一个新目录；如失败，测试重试和更换位置。
