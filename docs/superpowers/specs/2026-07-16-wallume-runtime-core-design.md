# Wallume 第三阶段：可测试运行时核心设计

日期：2026-07-16

摘要：本设计定义不依赖 AppKit 或 AVFoundation 的播放运行时核心。它以稳定显示器 ID 管理会话，按媒体 ID 共享播放资源，并用可组合暂停原因控制资源状态。

## 1. 目标与边界

本批实现第三阶段的可测试运行时核心：多显示器会话模型、按媒体共享的播放资源、暂停策略和可观测运行指标。它为后续 AppKit 桌面窗口与 AVFoundation 实际播放器提供稳定接口。

本批不创建桌面窗口、不读取真实 `NSScreen`、不启动真实视频播放、不写入锁屏系统文件，也不实现应用壳或 UI。实际 RSS、CPU、GPU 指标只在后续真实运行时接入后做实机基准测试。

## 2. 决策

- 采用纯 Swift 核心与可注入平台适配器；AppKit、屏幕枚举和 AVFoundation 播放器留在边缘层。
- `RuntimeCoordinator` 是 actor，也是唯一可变运行时状态的所有者。
- 显示器以稳定 `DisplayID` 标识，而非以短生命周期的 `NSScreen` 实例标识。
- 共享资源以 `MediaItem.id` 为键。多个显示器分配同一媒体时，只租用一个播放资源；最后一个会话释放后才释放该资源。
- 暂停状态由原因集合表示。用户暂停、前台遮挡、锁屏、低电量或系统睡眠中的任一原因均会暂停；只有原因集合清空才恢复。
- 资源切换遵循“先取得新资源、再替换会话、最后释放旧资源”。取得新资源失败时，原会话和原媒体保持不变。

## 3. 模型与接口

`DisplayID` 是 `Sendable`、`Hashable` 的稳定显示器标识。`DisplaySession` 记录该显示器当前媒体 ID、资源 ID 与会话状态。

`RuntimeEnvironment` 是不可变值，携带用户暂停、前台遮挡、锁屏、低电量和系统睡眠等暂停信号。核心仅消费此快照；未来平台观察器负责将 macOS 通知转换为快照更新。

`PlaybackResource` 是由 `PlayerFactory` 创建、暂停、恢复和释放的抽象。生产实现可以包装 `AVPlayer`，而测试实现只记录调用。`PlayerPool` 负责按媒体 ID 获取和归还引用计数资源。

`MediaCatalog` 只读查询已注册 `MediaItem`，使协调器在租用资源前验证媒体 ID 与受控变体 URL。生产实现包装 `MediaLibrary`，测试实现提供内存目录。

`RuntimeCoordinator.reconcile(displays:assignments:environment:)` 接收完整显示器、媒体分配和环境快照，并以增量方式创建、更新或关闭会话。它返回只读 `RuntimeSnapshot`，其中包含会话、共享资源引用计数、有效暂停原因、资源创建次数和故障信息。

## 4. 状态与故障规则

协调器会删除不再存在显示器的会话，创建新显示器的会话，并仅在媒体分配发生变化时切换资源。重复提交完全相同的快照必须幂等，既不重新创建资源，也不重复发出播放/暂停调用。

只允许分配仍存在于媒体库的 `MediaItem`。未知、已删除或不能创建播放资源的媒体会生成该显示器的结构化故障，并保留其原有会话；其他显示器继续运行。该类故障绝不触发锁屏操作。

环境暂停在资源层聚合：只要至少一个暂停原因存在，所有活跃资源均处于暂停状态；原因清空后，仍被会话引用的资源恢复播放。没有会话引用的资源必须被释放，而不是仅暂停。

## 5. 测试与验收

测试通过注入的媒体目录、播放器工厂和播放资源完成，不访问真实屏幕、媒体文件或系统壁纸目录。至少覆盖：

- 显示器热插拔和会话清理；
- 同媒体跨屏共享一个资源；
- 切换媒体后旧资源仅在最后一个引用释放时才释放；
- 多个暂停原因叠加与逐一解除；
- 资源创建失败时保留旧会话并隔离故障；
- 相同快照的幂等性；
- 快照指标的资源数、会话数、暂停原因和故障可观测性。

每个行为以 TDD 实现：先运行失败测试，再写最小实现。阶段验收要求聚焦测试、完整 `swift test`、release 构建和 `git diff --check` 均通过。

## 6. 实施顺序

1. 建立运行时模型、故障和只读快照。
2. 实现引用计数 `PlayerPool` 与测试替身。
3. 实现 actor 协调器的显示器会话差量更新。
4. 加入暂停策略和运行指标。
5. 记录运行时契约与验收结果。

## 7. 后续衔接

下一批将新增 AppKit 显示器观察器、桌面窗口承载层和 AVFoundation 播放资源适配器，但必须复用本批接口，不能将平台对象泄漏进核心。性能阈值在该真实运行时可执行后，使用 M1/macOS 14 起的实机基准验证。
