# Wallume 基础设置与诊断导出设计

日期：2026-07-17

## 目标与边界

本子批交付登录启动、启动时打开图库、低电量自动暂停、应用信息和本地诊断导出。音量、语言切换、缓存清理、图库重建和完全重置不在本批范围。

## 组件

- `ApplicationSettings`：包含 `launchAtLogin`、`openGalleryAtLaunch`、`pauseInLowPowerMode` 的强类型快照。
- `SettingsStore`：管理普通偏好、登录项命令、错误和事件。
- `LoginItemControlling`：封装登录项查询、注册和注销；生产实现使用 `SMAppService`。
- `DiagnosticsExportService`：组合脱敏设置、锁屏摘要、最近性能报告、构建与系统信息。
- `SettingsView`：显示开关、应用/目录信息、Finder 入口和导出操作。

## 偏好行为

- 登录时启动默认关闭，只有用户主动开启。系统注册或注销失败时保留旧值并显示错误。
- 启动时打开图库默认关闭，复用现有稳定 `UserDefaults` 键，下次启动生效。
- 低电量模式暂停默认开启。系统监控始终检测低电量，但只有偏好开启时才把 `.lowPower` 加入有效暂停原因；设置变化立即触发运行时重算。

普通偏好使用注入式 `UserDefaults` 域测试。Store 发布完整快照，避免页面直接读写默认值或调用 ServiceManagement。

## 应用信息与诊断

页面显示应用版本、Wallume 数据目录和诊断目录，并能在 Finder 中打开。诊断导出由用户选择目标位置，包含构建/系统摘要、脱敏设置、锁屏状态与最近事务摘要、最近性能报告和当前错误摘要。

导出不得包含媒体文件、缩略图、视频内容、系统备份内容或未脱敏的用户主目录，不执行网络请求。导出失败不修改内部状态，允许重新选择位置。

## 生命周期与失败

设置在显示器分配和运行时启动前加载。登录项状态以系统查询为准；偏好文件或系统 API 失败只影响对应设置。设置页面销毁不停止 Store；应用退出取消未完成的诊断导出，但不撤销已生效偏好。

## 测试与门禁

覆盖默认值、持久化、旧键兼容、登录项成功与失败回滚、低电量策略即时生效、目录信息、诊断脱敏、导出失败和 SwiftUI 渲染。完成时运行全量测试、四产品 Release 构建、`git diff --check` 和完成性审查。
